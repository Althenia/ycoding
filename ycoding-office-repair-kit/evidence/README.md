# Evidence storage

Store actual sanitized evidence here and index it in `tracking/evidence.json`. Original screenshots in `references/` are baseline/reference material, not proof of a fixed app. `local-audit-*` folders are candidate inventory output, not native or provider verification.

Suggested files: `R1-real-prompt.md`, `R2-dark-default.png`, `R2-light-200.png`, `R2-layout.json`, `R3-settings-restart.md`, `R4-office-runtime.mp4`, `R5-reconnect.md`, `R6-local-export.md`. These are naming examples, not files/results that already exist.

Record revision and dirty state, exact scenario, real capture conditions and the source kind. Review logs/images for credentials, transcript secrets and personal details before sharing. Never archive raw credential/config stores. Keep generated build caches and dependencies outside this kit.
