## Native cases

Launch a fresh preserved copy of the final rebuilt OUTER `.app`; an extracted inner run copy is a different post-launch artifact. Record the immutable delivery candidate and the extracted run copy separately. Keep the frozen backend, CLI output, lockfile and all earlier candidates unchanged.

1. Read the approved shared endpoint, use Desktop's Connect UI to save that endpoint only, and read it back. Record an already-correct saved value honestly; it does not prove a save occurred.
2. Confirm the final native window, WebView and backend connection stay alive without a new attributable crash. Record executable identity and actual capture paths.
3. Discover an existing ordinary populated root and navigate through a reported child to a reported grandchild, then back. Compare displayed identities with read-only API metadata. Confirm internal compaction helpers do not become ordinary roots. Do not send a prompt or create data to populate the journey.
4. Capture wide and compact native populated conversation states, collapsed and expanded long activity, sidebar/control states and Projects member selection. Measure actual native DOM scrollWidth/clientWidth, both gutters, transcript/composer centers and scrollbar geometry. Accessibility frames or browser-fixture geometry are not substitutes for DOM properties.
5. Observe native motion and reduced-motion behavior without changing system preferences. Use a supported app/inspector observation route or record the exact missing capability. Inspect sparse/populated Projects only when those states already exist; never mutate Project/session data to manufacture them.
6. Close only the verification process when its work is finished, restore any task-owned staging, and verify the protected services/processes and immutable candidates. Do not clear WebView storage or claim its cache is unchanged without evidence.

For the Desktop management surfaces, use an approved isolated macOS GUI runner with a clean WebKit store, task-owned window and preferences, and a synthetic backend. ## Evidence and limits

Keep each case Not Run until its actual test or native observation completes. Record command, exit code, pass/fail/filter counts, source revision, environment and screenshot/geometry paths. Preserve RED, setup failures and native launch failures separately from later passing evidence. Reuse attributable checks only when their code, input and environment remain unchanged.

A browser render proves the local renderer under its synthetic transport. Native frames prove only visible native content. Neither proves the other, source fidelity, user acceptance, installation or merge approval. If a mandatory native state, DOM observation route or permission is unavailable, name that prerequisite and leave the case blocked rather than manufacturing data or relaxing the requirement.
