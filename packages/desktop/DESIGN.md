# Desktop design

## Overview

The native Tauri 2 WebView presents a backend connection flow, then a Session workspace: a grouped Sessions rail, New chat placement, a conversation with a pinned identity header, a transcript and a docked composer, and a command palette. It uses the existing web semantic tokens and Geist faces from `apps/web/src/styles/tokens.css`. It is not the remote browser workspace and reuses none of its relay-bound components. The operating system owns the native titlebar, window controls and menus; renderer controls use owned DOM appearance and native keyboard semantics.

Every control maps to a method the frozen desktop bridge exposes: preferences, state, connect, disconnect, Session list, repositories, messages, create Session, prompt, interrupt, pending permission and form requests, replies to them, and the state, event and resync listeners. A capability the bridge lacks is absent or stated as unavailable, never simulated.

## Principles

- Make the backend choice explicit: nothing connects until the user activates Start or Connect.
- State ownership in words: a private backend stops with the window; a shared backend keeps running.
- Inherit the web token roles and Geist faces and add no desktop palette; follow the root open-hierarchy rule (`../../DESIGN.md` R12).
- Never show unconfirmed work as done: a draft keeps its text and identity until the backend confirms it.
- Show unknown as unknown: unreported status or context is stated as unavailable, never as zero or idle.

## Accessibility

Keep browser magnification enabled in the native renderer; do not copy the installed-PWA zoom lock. The transcript is a labelled ordered list with a separate polite status for finished responses; the rail is a navigation landmark and the main column is the page's main landmark. The palette is a modal dialog that contains focus. Follow the system light/dark preference with the existing token themes. Use no decorative animation. Forced colors retains system indicators/boundaries and marks the current row and active option with an outline. Verify keyboard operation, long endpoint/title wrapping, pending/failure, 200% zoom and narrow native content without horizontal overflow. A stylesheet/source pass does not replace a native-window render check.

## Bridge gaps

The frozen bridge has no method for a bulk pending or persisted run-status read, guardrail or question requests and replies, agent catalogs, decision grades, fork or attachments. The desktop UI shows none of these as working until the bridge provides them.
