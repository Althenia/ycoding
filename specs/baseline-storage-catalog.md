# Baseline storage catalog

The baseline exporter reconciles its isolated Core and Meeting SQLite databases against this table. Core has 49 tables, including the two bootstrap tables; Meeting has nine tables in its separate database. Missing, extra, or duplicate table names fail export. The exporter preserves row values and rejects nonempty WAL files before freezing the semantic fixture.
