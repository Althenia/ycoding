# Cue & Recall (0.13.4, unreleased)

## Changed

- Memory search reuses a local BM25 index without changing the Markdown collection.
- Set `metadata.activation` to `manual` in `SKILL.md` to keep a skill available by name without offering it in automatic guidance.
- New memory entries require a YAML mapping between two `---` lines. A write with a missing closing line or duplicate key fails before it creates the entry.

## Fixed

- After a Session reopens or compaction completes, the first provider request restores eligible skills with a recorded activation origin and retrieves permitted repository references. A missing source, an unverified activation, or a denied permission leaves the item out. Text from an old command does not invoke it again.
- Memory search includes the raw text of older entries that lack a closing `---`. A warning names the affected entry. To repair it, read the entry, add the delimiter, and write it with the digest from that read. Until then, its ID, bytes and digest stay unchanged.
