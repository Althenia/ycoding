# YCoding v0.13.4

## Fixed

- If startup fails because a global configuration file or a file it references is missing, is a directory, or cannot be read, the CLI explains what to check without exposing configuration values or private paths.
- Clients can submit deferred Form answers by field name, including checkbox and number values.
- Pinning a Session that is already pinned no longer writes to the database.

## Known issue

The restart failure reported in v0.13.3 remains open. Its trigger is unknown. The clearer configuration error does not establish that the reported failure was configuration-related.
