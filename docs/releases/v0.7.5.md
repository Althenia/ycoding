# YCoding v0.7.5

## Added

- Add an Office view to the remote workspace. Switch Conversation to Office to see the selected Session, other loaded Sessions, and its reported subagents as characters in a pixel office beside the same transcript, requests, and composer. The office has a CEO office, Developer room, Research lab, QA lab, Meeting room, Relax lounge, and entrance.
- Office characters work in the room for their responsibility. Top-level Sessions work in the CEO office. A subagent works in the QA lab or Research lab when its agent name, or otherwise the first three words of its task, name review, testing, or research work, and in the Developer room otherwise. Characters stay at their desks unless idle. Idle characters wander and chat in the lounge. Characters enter and leave through the entrance. A live delegation meets in the Meeting room, and a live report walks the subagent to its parent. Loading history, reconnecting, and returning to the tab never replay these walks. Settings → Office controls the default view, motion, bubbles, labels, camera following, and rendering quality.
- Add **Open context breakdown** to the TUI command palette. It shows Session, model, context, token, message, cost, and time stats for the latest request. It also shows an estimated breakdown of the context window across system, tools, user, assistant, reasoning, tool calls and results, and other content, as a bar, legend, and token table.
- Sort every TUI usage table by any column: click a header or press `d` date/name, `t` total tokens, `c` cost, `s` steps, `i` input, `o` output, `g` reasoning, `a` cache read, or `w` cache write. The Overview model table sorts too.
- Offer **Connect Chrome** in the landing command palette. It scopes pairing to a Session in the current Location and creates an idle Session only when none exists.

## Changed

- Group the remote Sessions table and conversation sidebar by workspace, and load 50 rows at a time as you scroll instead of loading the complete inventory.
- Show your remote prompts as right-aligned bubbles. Show Read only after YCoding consumes the prompt. Show reasoning as a compact expandable section, and hide messages covered by a completed compaction from the browser view.
- Show every estimated cost in the TUI as a dollar amount. Requests without catalog pricing count as $0.00, and totals add up priced spend instead of showing Not reported.
- Remove the live SHELLS section from the Session sidebar; running shells remain in the composer's shell tab.
- Open Usage from the landing footer with leader+Shift+U, beside the command hint.
- Apply a pending model or variant choice when `/goal` sets or resumes a goal.
- Remove the Usage Stats note about unretained usage.

## Fixed

- Report a machine as offline when the relay has no local agent for the workspace read, and restore it on the next successful read.
- Widen the desktop machine selector while keeping machine names on one line.

## Upgrade notes

- Reload the remote workspace to load the updated browser client. Existing device enrollments remain valid.
- Update YCoding on each machine so the Office can list its subagents. Machines on earlier versions keep working and show that subagents are not reported.
- The context breakdown appears after each Session's next model step.
- Sessions that recorded unpriced requests before this release keep only the priced spend recorded afterwards for those models.
