# YCoding v0.7.16

## Added

- Paired Chrome shows a control indicator, a marked tab title and a cursor that moves to action targets. Profile tabs have exclusive per-Session control, so another Session cannot silently take over a held tab. Release control when finished; confirmed cleanup also runs when the Session becomes idle.
- Shared Session notices survive reloads and remain until read. Dismissals and **Read all** synchronize across browsers viewing the same machine, and older stored notices load on demand.
- **Settings → Notifications** adds **Send test alert** and **Re-enable** to check whether the push service accepted an alert and restore an expired device subscription. Acceptance does not override the device's notification permissions or Focus settings.

## Changed

- Office presents a shared pixel workspace with varied desks, personal details, lounge seating, a meeting area and a coffee corner. It opens near the selected agent at a readable working scale. Drag, wheel, trackpad and focused arrow keys pan the floor; **Fit** shows the whole floor and preserves that overview through resize. Controls and the Agents list remain reachable below workspace notices.
- Remote navigation contains **Sessions**, **Conversation**, **Usage** and **Settings**. Team is a header icon with its active count; jump controls float above the composer, and Edited files collapses to one expandable row on phones, tablets and desktops. A healthy connection does not occupy an extra status row; reconnecting, offline and error states remain visible.
- Captured changes stay with each prompt's reply, with repeated edits aggregated by file and resumed subagent work attributed to the request that dispatched it. Counts describe recorded edit activity rather than a net working-tree diff; earlier summaries are not carried into later prompts.
- Built-in commit guidance keeps the user's existing Git author and committer identity and omits co-author trailers. A missing Git identity is reported instead of invented.
- macOS computer-use apps use a stable release signing identity so future signed updates can retain their privacy grants.

## Fixed

- Composer suggestions have a visible **Close** control, fit the available space above the field, and dismiss without changing the draft or immediately reopening the same token. Outside taps leave focus with the chosen control.
- Usage keeps full provider totals below the donut and long names inside their cards. One accessible provider legend replaces the duplicate monthly table; the daily chart keeps its table.
- System switches govern closed-app push categories, including choices changed during registration or in another Settings tab. Machine offline alerts follow a confirmed outage rather than a browser connection drop, and page and push alerts for the same outage share one identity.
- Setting a remote goal releases the composer immediately and shows **Setting goal** without blocking another prompt. A goal request is confirmed only by its own successful response. Failed or uncertain requests restore the objective to that Session's empty draft without overwriting newer typing; replies from a replaced connection cannot rewrite drafts.
- A Session whose last run failed shows **Failed**, rather than a waiting-for-your-decision indicator.
- Anthropic tool definitions retain typed arguments for union-root schemas, including referenced branches and constraints belonging to the root object.
- The updater accepts the files required by the selected release and ignores other archive entries. Release archives keep the supported installer layout, with license files attached separately to the release.
- Local installation reports the computer-use app's actual signing identity and distinguishes stable signing from an ad-hoc build.

## Upgrade notes

- Reload the remote workspace, or reopen the installed app, to load the updated browser client.
- Run `ycoding update` on each machine. An idle background server restarts automatically; if work is still running, let it finish before running `ycoding service restart` to use the updated runtime.
- Update the local runtime and browser client together for per-prompt captured changes. Reload the YCoding Chrome extension at `chrome://extensions` to activate the updated control protocol and indicators.
- Reopen each subscribed browser or installed app once to apply its current System switches to background push.
- When updating from an ad-hoc-signed macOS helper, enable the installed **YCoding Computer Use** app in Privacy & Security again if macOS requires it.
