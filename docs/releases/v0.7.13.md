# YCoding v0.7.13

## Added

- Join a remote workspace from an invite link. Opening the link and choosing **Accept invite** creates your own account and shows your personal access key once; sign in with that access key on your phone and other computers. Each invite link works only once.

## Changed

- Show slim, rounded scrollbars on the YCoding website and in the remote workspace in desktop browsers; the scrollbar widens under the pointer and turns brand green while you drag it. Remote scrolling areas keep room for the scrollbar, so content no longer shifts when one appears. Touch devices and high-contrast mode keep the system scrollbars.

## Fixed

- Make each file's added and removed line counts in the remote **Edited files** card and the TUI change summary match the changes shown when you expand it, including edits from completed subagents. After a compaction with no completed reply, each file shows its latest recorded change with counts for that change.
- Let the **Edited files** card use the full width of remote Conversation.
- Stop showing impossible generation speeds, such as 30,000 tok/s, when a response arrives in one burst: without provider timing, a measurement shorter than one second stays hidden.

## Upgrade notes

- Reload the remote workspace to load the updated browser client.
- Update YCoding on each machine, then open the TUI or run `ycoding service restart` so its background server runs the new version. The Edited files card and the corrected generation speed need the updated machine; a machine without the update shows no Edited files card.
