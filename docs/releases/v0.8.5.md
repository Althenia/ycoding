# YCoding v0.8.5

## Fixed

- The web workspace reconnects to the machine it last used after a reload, instead of asking again whenever more than one machine is online. An explicit disconnect or sign-out clears the remembered machine.
- A connection heartbeat does not count as a reconnect. A Session's status dots and the running and recent lists are not cleared and re-read about twice a minute, and the stored notices are not re-synced on each heartbeat.
