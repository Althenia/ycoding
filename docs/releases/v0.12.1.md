# YCoding v0.12.1

## Changed

- Web and Desktop use the Instrument design: one shared palette of plane, line, ink and cobalt colors with clearer field and pane boundaries, so state, focus and structure read at a glance in light and dark themes.
- The Web workspace from 768px wide shows a labeled activity bar for Chat, Sessions, Projects, Workspaces, Usage and Settings, a searchable Session list column, and a status bar with connection, machine, model, autonomy, context and running-Session readouts. Unreported values are left out rather than shown as zero.
- While a Session runs, a thin mint trace follows the status bar and conversation header and branches when a child task starts. With reduced motion turned on, every loop stops and the trace shows as a static line.
- Pending request cards use a tonal header band by kind (amber for permissions and guardrails, sky for questions and forms, violet for reviews), and the New chat repository picker and focus rings follow the same palette.
- Desktop groups its Session list into Needs action, Running, Pinned and Recent, and its minimum window size is 1000×600.
- Agents finishing or integrating work now remove unused temporary files, remove completed or merged worktrees with non-force `git worktree remove`, prune dead worktree registrations, and delete merged local branches with `git branch -d`, leaving dirty, active or unmerged work in place.
