# YCoding v0.12.1

## Changed

- The full-featured Bun edition includes the Field Notes redesign on Web and in the signed macOS Desktop app. The conversation header can hide the Session list, and Desktop groups Sessions by what needs your attention.
- The composer keeps Send visible on one row. Narrow layouts move secondary actions into Controls without clearing the draft.
- The pending-message tray shows a one-line preview ending in `..` when truncated. Open it to steer or delete individual messages. You can also delete an unread sent message; if YCoding reads it before the delete completes, the message stays in the conversation.
- This edition includes signed YCoding Interaction for macOS, the Chrome extension, Markdown code cards, image previews, and Goal Mode with rework tracking and named-check verification.

## Fixed

- On Bun 0.12.x, `ycoding update` can install a newer 0.12.x release but will not switch to Rust when 0.13.0 or later is the latest release. To switch editions, specify the target explicitly with `ycoding update --version <version>`.
