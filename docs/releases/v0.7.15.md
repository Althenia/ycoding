# YCoding v0.7.15

## Fixed

- In the remote workspace, the composer's outcome toasts (**Sent**, **Failed**, and **Outcome unknown**) appear below the header and the Team row instead of covering their buttons, and close after about six seconds, as notification toasts do. Hovering over or focusing a toast keeps it open, and its close button still dismisses it. Notification toasts also appear below the Team row when a Session is open, and the two kinds share at most three toasts on screen, outcome toasts first.
- Agent edits insert replacement text exactly as written. Replacement text containing `$&`, `` $` ``, `$'`, or `$$`, which is common in shell scripts, regular expressions, and templates, was expanded as a JavaScript replacement pattern and could corrupt the edited file.

## Upgrade notes

- Reload the remote workspace, or reopen the installed app, to load the updated browser client. The toast change comes from the browser client alone.
- Run `ycoding update` on each machine. Updating from 0.7.14 restarts an idle background server, so agent edits use the fix right away. If Sessions have running work, or you update from an earlier release, open the TUI or run `ycoding service restart` afterwards so the background server runs 0.7.15.
