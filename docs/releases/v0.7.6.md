# YCoding v0.7.6

## Added

- Add a Usage page to the remote workspace. Each provider card shows its reported quota windows with meters, remaining amounts, reset countdowns, and pace. Spend tiles cover today, yesterday, and the last 30 days, a daily spend chart has a table view, and breakdowns by model, Session, project, and agent sort by any column. Costs are estimates from recorded usage and model pricing, not provider bills.
- Show the OpenRouter credit balance in the TUI and on the web, with a Credits meter, Today, This Week, and This Month spend, and a Key Limit only for capped keys.
- Report GitHub Copilot usage as AI credits, with extra usage, organization credits and spend for organization owners and billing managers, and Chat and Completions.
- Report xAI Grok, OpenCode Go, and Z.ai quotas from logins YCoding already stores, and a separately labeled YCoding local Today spend for Claude, Codex, Grok, and OpenCode from this machine's priced requests.
- Start a remote Session from a composer: choose the repository, agent, model, and variant, then send the first prompt or command.
- Autocomplete `/` commands, `@` files, agents, and references, and `$` or `#` skills in the remote composer, and switch the agent, model, and variant for the next send.
- Send push alerts to a closed browser or installed app when a Session needs your decision or stops running. Turn them on in Settings → Push to this device; opening an alert goes to its Session.
- Collect recent alerts in a notification center, and mark Sessions, the Conversation tab, and navigation while a decision is waiting.
- Show a status bar above the remote composer with the autonomy level, current activity and elapsed time, and the active goal with Stop.
- Open a Session directly with `/remote#session=<id>` and the new-session composer with `/remote#new-session`.
- Animate the public site, documentation, and changelog, with motion turned off under reduced motion. The documentation contents rail follows the section you are reading.

## Changed

- List workspaces by name in a Sessions sidebar, or a menu on phones, without the global project or temporary folders. Show top-level Sessions only, 25 at a time: running first, then pinned, then most recent.
- Render remote replies as formatted Markdown. Thinking and tool rows stay collapsed with their status, duration, and a live activity indicator, and each reply ends with its agent, model, and duration. Prompt bubbles contain only your text, with the delivery state below.
- Show only the selected Session's main agent and its subagents in the Office, each with a unique name. An Agents list shows each character's room and status, the office fills the workspace, and its toolbar uses icons.
- Use branded menus instead of native dropdowns in the remote workspace.
- Show `Unknown` or `No usage yet` instead of bare dashes in the TUI usage views, and label counted limits as used amounts.
- Remove the `ntfy` tool and its configuration. Web push alerts and local desktop notifications cover attention alerts; a remaining `ntfy` configuration key is ignored.

## Fixed

- Skip compaction when compacting earlier history cannot bring a request under the model's context window, such as a new Session whose fixed prompt already fills a small window.
- Reload the Usage page's data after the connection to the machine changes instead of waiting indefinitely.
- Keep the desktop header, brand, and navigation within the window at 1024–1279 px wide.

## Upgrade notes

- Reload the remote workspace to load the updated browser client. Existing device enrollments remain valid.
- Update YCoding on each machine to use the Usage page, composer autocomplete and pickers, live status marks, and push alerts. Machines on earlier versions keep working; the Usage page asks you to update them.
- Push alerts stay unavailable until the relay operator configures Web Push keys and applies the push subscription database migration.
- Remove any `ntfy` entry from your configuration; it no longer has an effect.
