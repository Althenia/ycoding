# YCoding v0.5.1

## Added

- Responsive remote web workspace for shared Sessions, prompts, streamed output, approvals, interruption, and Session autonomy controls.
- Google sign-in, device enrollment, and explicit Session sharing through `ycoding remote`. Model, shell, tool, and filesystem execution remain on the enrolled machine.
- Public installation guides, documentation, and release history with light and dark themes and reduced-motion support.

## Fixed

- Terminate the isolated browser's owned process group during shutdown, including renderer processes when Chrome is suspended.
- Recognize signal-based browser exits during cleanup.
- Improve light-theme offline status text contrast against its translucent background.
- Preserve Unicode across terminal-output pages and prevent stale remote connections or revoked sharing from exposing current Session data.

## Distribution

- The terminal executable includes remote commands. The responsive web client complements the same local runtime.
- Isolated-browser support requires macOS arm64 with installed Google Chrome major 152.
