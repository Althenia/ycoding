# YCoding v0.10.13

## Added

- Start a subagent with selected historical context using `shared_context.message_ids`. Choose up to eight distinct parent user messages without files or agent mentions, or completed text-only assistant messages. The rendered prefix is limited to 32 KiB and the complete prompt to 64 KiB; larger selections are rejected instead of truncated. The first admitted snapshot is immutable and retries reuse it. The text is added before the task as ordinary user evidence; it grants no permissions or approvals and does not activate skills. Fresh child context remains the default.
- `efficiency.prompt_cache.family_scope` defaults to `session`. The opt-in `family-experiment` uses a compatible family cache key only for eligible direct public OpenAI HTTP Responses requests with GPT-5.6-or-later generated breakpoints, verified account identity and selected context. Codex, WebSocket, OpenRouter and other routes keep Session-scoped keys. This experiment reports no live cache-hit or savings guarantee.

## Changed

- Web Usage quota cards show concise forecast status and move source, stability, exact update time and full forecast diagnostics into an accessible Details dialog that preserves card positions. Recorded consumption on the backend uses aligned provider/model/profile, token-rate and estimated-cost rows, with exact rates, coverage and observation times in Details. Missing prices remain unreported.
- TUI Usage shows concise quota forecasts and compact recorded-consumption rows; press `d` to expand exact quota and consumption details. Narrow terminals stack long identities instead of clipping the rate and cost columns.
- Date-filtered Usage reports apply time bounds within indexed time-and-ID page seeks, preserving exact accounting totals without rescanning the full date range.
- The Meeting page separates Setup, Live, Finalizing, Recovery and Review. Finalizing distinguishes audio processing from analysis. Retry processes retained failed audio without restarting capture; Review retained transcript keeps the recovery warning and Retry available without discarding audio or restarting capture.
- TUI autonomy rows use concise decision labels for permission, guardrail and question requests. The Questions row reflects the Session's effective auto-answer behavior; `/auto-answer` remains separate from YOLO.

## Fixed

- Git HEAD monitoring is ready when Location initialization completes, including symlinked `.git` directories, so immediate branch updates are observed.
- Closing the custom-provider dialog cancels deferred focus; adding a model replaces its earlier focus target, and destroyed inputs are ignored.
