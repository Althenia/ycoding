# YCoding v0.11.6

## Added

+ Browser observations offer stable role-and-name locators and optional diffs; capture can target an element, a rectangle or the full page. Agents can inspect and answer JavaScript dialogs and deliver an owned tab to leave the finished work open after control ends.
+ On macOS, `desktop.observe` combines an Accessibility diff and screenshot; `desktop.paste` supports text, Markdown and HTML while restoring the previous clipboard. Clicks and keys support held input and key chords.
+ `desktop.history` lists and reads the calling Session's local desktop-control records, or clears them with permission and guardrail review. Records contain action metadata and screenshot references, not image bytes or audio; files older than 30 days or beyond the newest 200 are pruned when recording starts.

## Changed

+ Controlled browser tabs show the YCoding favicon instead of changing page titles; the original favicons are restored when control ends. Pinned tabs and pages that block the marker image cannot be controlled. After updating, reload the unpacked extension in the browser.
+ The browser extension can also be loaded in Edge and Brave. Each browser pairs separately; native tab-strip rendering of the control marker in those browsers remains a manual check.
+ Desktop calls show a non-activating cursor and action label. Native pointer and keyboard input targets the selected process without moving the user's pointer or changing the user's focus; an application may still activate itself.
+ Desktop window permission is saved per app, while terminals ask every time. Security and credential apps are blocked by default; desktop mutations receive guardrail review, remote Sessions use separate permissions, and desktop operations fail closed while the screen is locked.
