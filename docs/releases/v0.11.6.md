# YCoding v0.11.6

## Added

+ The Switch session dialog in the terminal groups root Sessions under Pinned, Waiting for action, Running and Recent, in that order, with no Session listed twice. Pinned, Waiting for action and Running include Sessions from every project and workspace, so work that needs attention is visible without switching workspaces; Recent stays scoped to the active workspace project and leaves out background Dots executors. Quick-switch slots 1-9 follow the global pin order, and a failed refresh keeps the previously shown waiting and running Sessions.

## Fixed

+ Project send no longer admits a steer or queued message for a member that is blocked on a pending question, permission or review. It names each pending request and points to answering it, escalating it or interrupting the member, so supervisors and the Master stop waiting for replies that cannot arrive.
+ Project inspect marks a pending question as needing an explicit decision while the member's answers mode is Manual, matching what answering it will accept.
+ When the Master escalates a request to you, it now explains that the request stays open as the member's own prompt, must be answered in that member's Session, and cannot be settled by messages or by answers the Master relays.
