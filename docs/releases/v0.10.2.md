# YCoding v0.10.2

## Added

- Turn a rough intent into a full prompt with `/prompt <intent>` in the TUI or web composer. A dialog lets you choose **Start a task**, **Steer**, **Queue follow-up**, or **Goal objective** (Steer and Queue follow-up appear inside a Session) and include **Project memory (this repository)** or **Global memory (shared knowledge)**. The draft fills an empty composer for review and is never sent automatically: Goal objective fills `/goal …`, and Queue follow-up marks the draft so it is sent as queued. On the landing or new-session screen, Start a task and Goal objective create the Session first. Choose the helper model with `efficiency.helper_models.prompt`; its requests appear in usage as `prompt`.

## Changed

- Guardrails no longer ask to review work outside the repository when it touches YCoding's own config, data, cache, state, temporary, bin, log, or repos directories, or a path your `external_directory` permission allows. Paths set to `ask` or `deny` are still reviewed, and hard reviews such as deleting the project or destructive Git still always ask.
- Session lists, today's spend, usage reports, and the start of each model request read faster on large histories. The first start after upgrading builds the new database indexes once.

## Fixed

- **Instructions updated** notices stay where the instructions changed, just before the reply that first used them, instead of sticking to the bottom of the transcript. This holds live and after reopening a Session, and the remote web shows the same notices.
- On phones and tablets, web sheets and dropdowns such as Agent and model, the model list, Select Color Scheme, and the command palette size to their content instead of filling the screen, and their options keep a normal row height.
- With the on-screen keyboard open, the web composer sits directly above the keyboard, and the Sessions, Usage, and Settings bar no longer takes space between them.
- The web **Hide composer** control has its own row and no longer covers the text you are typing.
- Opening the web model list with hundreds of models no longer freezes the page.
- The web Sessions screen no longer reserves empty space beneath the loading cards.
