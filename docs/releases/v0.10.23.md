# YCoding v0.10.23

## Changed

- The decision model, including explicit `decision` tool calls, and automatic permission, guardrail, and question evaluators receive the Session's current goal, retained compaction summary, recent human inputs, pending steers, step and tool progress, recent review identities, the permission ceiling, and the goals and inputs of up to two managed ancestors. Queued follow-up work does not count as current authority. Explicit decision results remain advisory.
- Decision helpers resolve ordinary reversible choices from the goal and recent inputs without asking for a recommendation. Indispensable facts, required approvals, and denials stay intact; assistant text, tool output, summaries, delegated claims, and earlier automatic decisions never count as human consent, and a newer explicit correction replaces earlier intent.
- A decision result is discarded when current instructions, goals, grants, reviews, or restrictions change while it is computed. Unrelated sibling-tool progress does not force a human handoff. A discarded result is never an approval or an answer.

## Fixed

- The command palette shows one control per automation flag with its actual state and a precise description. Inherited automation is identified separately from local settings, and descriptions remain readable at 80 columns.
- A fresh human steer with YOLO enabled releases earlier unanswered questions, forms, and their still-open review items without inventing answers. A cancelled upload can resume local-only work; queued follow-ups, repeated prompt IDs, other Sessions, and permission or hard-review requests retain their own boundaries.
- Permission and guardrail assessments receive applicable rules, matching prior decisions, resolved targets, and same-call permission evidence. Current policy is checked again before applying a model result. Invalid guardrail configuration and genuine hard approvals remain human decisions.
- Remote MCP confirms uncertain model selections from fresh Session state without repeating the switch, and permits a retry with the same prompt ID through durable admission. Unresolved lanes report read-only recovery guidance while reads and other Sessions remain available. Profile rebinding and other unconfirmed actions are not inferred or repeated.
- Remote model switches use a five-minute allowance for interruption and compaction. The browser can confirm the exact selected model after a lost response, preserves genuinely unknown outcomes, and discards confirmations from an old Session or connection. The TUI keeps recovery guidance and the full device URL visible at 80 columns.
- MCP connections report authentication required after the latest stored refresh token is rejected, withdraw stale tools, and do not retry the failed call through another stored profile. Relay MCP off guidance calls for enabling it and a fresh sign-in and consent in each client.
