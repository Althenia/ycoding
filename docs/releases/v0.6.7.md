# YCoding v0.6.7

## Added

- Configure a custom OpenAI-compatible endpoint from the TUI's `/connect` menu, including models, Chat or Responses API selection, optional model discovery, and named credential profiles.
- Connect to Runpod Serverless Jobs endpoints using the Ollama or vLLM worker route.
- Mark verified normal-Session work complete with the local `task_complete` tool to request a TUI completion alert without configuring remote notifications.

## Fixed

- Keep ordinary successful idle, unfinished child tasks, and root-owned background shells from producing premature completion alerts. Completed goals alert after work settles; pending human requests, failures, and terminal goal outcomes retain their attention alerts.
