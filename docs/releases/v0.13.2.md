# YCoding v0.13.2

## Fixed

- Antigravity sign-in works in the released macOS app and CLI. The v0.13.1 native runtime shipped without a Google OAuth client, so connecting an Antigravity account was rejected.
- Muse (Meta) account sign-in uses the client embedded in the same builds. Muse needs only its client ID; the client secret is optional.

## Known limitations

A YCoding event starting a turn on an idle Dot directly over the ChatGPT app executor channel was not verified live for this release. `ycoding decision watch --deliver dot` sends events only while a watch runs with `--family --follow` on an existing root Session.
