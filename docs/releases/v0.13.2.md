# YCoding v0.13.2

## Fixed

- Keep Machine Awake on macOS prevents the display and system from sleeping due to inactivity. The TUI and Web show the display hold separately. Closing the lid can still put the Mac to sleep.
- Rust keeps the reusable prompt prefix stable on Codex, Claude Code, and Antigravity when Session state changes. Each provider still decides whether to reuse cached content.
- Rust announces a change to active Session instructions once, rather than repeating it on the next turn.

## Changed

- Stable Rust releases take the GitHub Latest badge. Existing Bun archives remain available, and switching an existing Bun installation to Rust still requires an explicit choice.
- Terminal, Desktop, and Web show OpenAI, Claude, Antigravity, OpenRouter, and Custom OpenAI-compatible Endpoint in the connect menu. Rust preserves credentials and Session history for retired providers but does not start new requests through them.
