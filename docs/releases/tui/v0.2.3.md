# YCoding v0.2.3

## Fixed

- TeamView notices stay in the message store but never render in the transcript.
- Every sidebar rail section is expandable again; defaults expand only `session`, `context`, and `todo`, with all other sections collapsed by default until the user expands them.
- Rail expand/collapse state persists across Session navigation, so entering a subagent chat and returning to the main chat preserves what was expanded or collapsed.
- Guardrail approvals no longer wait invisibly: pending guardrail reviews surface at the composer like permission prompts, pause the composer with a reason, and always render a transcript row, so `rm` commands that need approval no longer read as hung.

## Changed

- Session-state and TeamView observations remain durable chronological messages and model-facing history; hiding them is presentation only.
- Rail attention opens any collapsed section and releases only attention-owned sections when cleared.
- Recursive deletion of multiple narrow targets is now an ordinary guardrail review instead of a human-only hard review.
- Recursive deletion directly below the home directory (for example `rm -rf ~/Documents`) now requires hard human review that custom allow rules cannot override; `/` and `~` remain denied.
