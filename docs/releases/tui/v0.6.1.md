# YCoding v0.6.1

## Fixed

+ Show and answer the questions created by the local agent in the remote workspace.
+ Render native forms with text, options, multiple selections, numbers, integers, booleans, defaults, and conditional fields. External steps expose safe HTTP(S) links and explicit acknowledgement.
+ Cancel pending forms from the remote workspace and keep replies scoped to their owning Session.
+ Track live form creation and settlement in the request queue and attention notifications.

## Changed

+ **Breaking Change:** Remote Forms require the coordinated v3 connector and web client. Stop the connector, upgrade YCoding, reload the remote workspace after deployment, and restart `ycoding remote connect`. Existing sign-ins and device enrollments remain valid unless independently expired or revoked.
+ Model and tool execution stay on the connected machine. Uncertain replies are not automatically replayed.
