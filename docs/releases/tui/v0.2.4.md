# YCoding v0.2.4

## Fixed

- Sending a prompt is no longer held behind a model or variant switch. While a drain owns the Session, the switch is requested and the admitted input resumes immediately instead of awaiting the switch, which waits for the running step to reach its boundary. Previously the composer stayed in its preparation phase for the whole step, the draft was never cleared, and every later send was refused. An idle Session still applies the switch before the prompt runs, and a rejected or over-budget switch reports separately without withholding the admitted prompt.
- A pending guardrail review now surfaces in every view that it can block, including a subagent chat and an autonomous Session. Previously a review raised by a subagent rendered no prompt and no transcript row in that subagent's view, so the subagent read as hung until the Session was interrupted.
- A pending permission request now surfaces for the viewed Session and its own descendants. Previously only a root view collected child permissions, so a subagent's own review rendered nothing.
- A terminal paste only transfers text, so an image on the host clipboard is never carried by the paste payload. The composer reads the host clipboard directly when an image-only clipboard arrives as an empty bracketed paste, and a pasted file path that resolves to a supported attachment type becomes a real attachment instead of literal text.

## Added

- **Send and steer now** (`<leader>d`, palette) admits the prompt, interrupts the active step so the boundary is reached immediately, then wakes the Session. The admitted steer is promoted by the successor drain rather than waiting for a long-running step to finish on its own. Interruption remains a no-op for an idle or locally unowned Session.

## Changed

- Guardrail and permission review rows render whenever the request is still awaiting a reply, so the row disappears on reply without a compaction boundary.
- Clipboard attachment tests cover the Ctrl+V gesture, the empty bracketed paste that a terminal sends for an image-only clipboard, and a pasted file path. Session-view tests cover pending guardrail and permission reviews arriving from the durable list and from live events.
- The TUI screen harness can enable the kitty keyboard protocol so modifier and leader sequences are exercised through the real renderer path.
