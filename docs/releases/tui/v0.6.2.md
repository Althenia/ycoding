# YCoding v0.6.2

## Added

+ Open a dedicated Usage screen from the Session footer or `<leader>Shift+U`, with retained backend totals, model breakdowns, time-based reports, Sessions, projects, agents, and an activity calendar.
+ Reopen BTW conversations from a separate Side chats tab, with distinct navigation back to the parent Session.

## Changed

+ Background update checks only announce available releases. Run `ycoding update` explicitly to install; `autoupdate: false` disables the checks.
+ **Breaking Change:** The built-in `TLDR` agent is replaced by `GSD`, an orchestration-only prompt profile that delegates implementation and validation. Change configured `default_agent: "TLDR"` or agent references to `GSD` or another maintained primary agent.
+ Goal activation, resume, and continuation generate context-aware steers. Goal steers have a distinct transcript presentation and do not grant human approval.
+ Automatic ntfy attention messages use sanitized Session context to describe the outcome or required action. Failed generation skips delivery.

## Fixed

+ Show quota status for every available connected provider, including providers unused by the current Session. Quotas use the active profile per provider; inactive profiles are not listed separately. Independent refresh failures preserve successful results.
+ Keep retained usage readable when a historical workspace has been deleted. Preserve recorded costs and token counts, and leave unavailable cost estimates unreported rather than zero.
+ Defer model and variant changes until prompt submission instead of interrupting active work when a picker selection changes. Failed switches retain the draft.
+ Refresh durable subagent status after reconnect and show each child Session's current todos.
+ Use the maintained YCoding branding in shared UI components and local OAuth callback pages.
