# YCoding v0.2.2

## Fixed

- Sidebar rail expand/collapse state is preserved when navigating between the main transcript and subagent chats and back.
- Session-state notices stay in the message store but never render in the transcript.

## Changed

- The sidebar rail expands only `session`, `context`, and `todo-list`. All other sections stay collapsed behind their header summaries; header toggles and attention events for those sections are ignored.
