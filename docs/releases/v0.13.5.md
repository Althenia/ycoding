# YCoding v0.13.5

## Added

- Cue & Recall v2 chooses context from one retrieval contract across memory, skills and transcripts. Selection combines BM25 with embeddings, falls back to lexical matching when the embedding model is unavailable, and applies per-kind and total size budgets.
- Each trusted cue and each recall selection becomes a durable Session event, so the TUI, Web and Desktop transcripts show why context was added. Refused candidates stay in the record with their reason, and a retry never records twice.
- The core library includes a harness adaptation engine with `disabled`, `adaptive`, `parallel` and `sequential` modes. It keeps only edits with contrast evidence that stay inside the authorization ceiling, never replaces or removes a guardrail, publishes each result as a reversible, content-addressed version, and records lessons from finished tasks as experience concepts in workspace memory. Session runs do not invoke it.
- The public event schema defines `coordination.subagent.request.blocked` for a refused subagent launch. It carries the requesting Session, the requested agent name, a reason (`concurrency-ceiling`, `agent-missing`, `permission-denied`, `project-paused` or `route-unavailable`) and the exact refusal message. The runtime does not emit it.

## Changed

- Memory reads and writes OKF v0.3 with typed concepts, source footnotes, lifecycle metadata and recoverable trash. Validation checks every concept's frontmatter against the v0.3 content schema and reports the field and specification section without quoting the rejected value.
- A declared v0.3 bundle ignores the legacy `timestamp` key for trust and freshness. A footnote definition is no longer read as a link, which removes false broken-link reports.
- Skills follow the Agent Skills specification: a skill is a `<directory>/SKILL.md` file whose `name` equals the directory name, and activation metadata covers events, commands, paths and keywords.

## Removed

- Project Artifacts and the `project_artifact` tool. On upgrade, the store drops their tables, deletes their Session events and boundary messages, and strips artifact provenance from stored events, messages and pending inputs.

## Fixed

- The TUI resends a request that failed as unsent once the connection returns, and shows a transient connection notice instead of an error toast when the resend cannot complete. Unsent errors name what did not happen, and a resynced event stream resubscribes in place.
