# YCoding v0.10.11

## Changed

- Decision-model guardrail reviews can ask for your judgment. While awake, an explicit escalation, uncertain choice, refusal, failure, or timeout opens the usual human review; confident approval still allows once and confident rejection blocks. Sleep rejects escalated reviews, including existing handoffs across the family, without waiting for input; plain human reviews remain pending.
- Escalated review prompts identify the model handoff. The terminal and web transcript retain a chronological awake-handoff notice with the reported choice and confidence, including after restart; interrupted reviews and actions are not restored or replayed. Choices that settle while asleep retain rejection provenance without a handoff notice.
- The shell queue runs as many commands as free memory and CPU allow, up to 10 at once on the machine and one per Session by default. Commands that start together cannot all count on the same free memory or CPU.
- When no queued command is running, the next queued command starts even if memory or CPU is short, so the queue never stalls.
- A queued command takes one of its Session family's shell slots only when it starts, so waiting commands leave those slots free for ordinary shell commands.
- A repeated queued command needs only as much free memory as its recent runs used: the highest peak of its last five recorded runs for the same command and working directory, capped by its memory limit. Only a run that exits successfully after at least one measurement can lower that amount; other runs can only raise it.

## Fixed

- Deleting a Session whose directory no longer exists works. The TUI session list and the API previously failed with an HTTP 500 error for such Sessions; opening them with `GET /api/session/:sessionID` now succeeds, and deleting one removes the Session and all of its subagent Sessions without recreating the directory.
- A command that exits immediately keeps its output. A fast command could return empty stdout and stderr when its process finished before the shell service received it.
