# YCoding v0.11.5

## Changed

+ This v0.11.5 re-release clarifies durable Session-state observations versus explicitly volatile outbound messages and adds regression coverage. The clarification changes no production behavior.

## Fixed

+ Public OpenAI Responses requests for GPT-5.6 and later keep durable chronological instruction updates eligible for cache breakpoints while preserving their role and order. Durable Session-state observations are replayed chronologically and remain eligible; outbound messages explicitly flagged volatile receive no generated breakpoint. Cache-hit or cost gains have not been measured.
+ Recognized read-only search and print commands avoid destructive-rule false positives for text they only inspect, including bounded reader wrappers, literal regex end anchors and plain input redirection. Executable pipelines, substitutions, unsupported arithmetic expansion, destructive commands, custom guardrails and catastrophic denies retain their checks. Recognition remains literal and bounded.
