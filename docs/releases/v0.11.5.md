# YCoding v0.11.5

## Fixed

+ Dots executor enrollment reconciles at every host start even when a computer rename is pending, adopting a server-confirmed executor ID for the account's own installation, so a second OS account on the same computer attaches as its own computer under its configured name instead of staying missing from the Dot's computers. Other attached computers are unaffected.
+ Generation speed is realistic: settled Session speed prefers provider-measured output tokens and duration when fully provider-timed (estimated `≈` only as fallback), sub-second generation windows no longer inflate tok/s in usage reports, and mean and percentile rates require at least three samples.
