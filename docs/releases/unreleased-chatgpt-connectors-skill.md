# ChatGPT connectors skill

## Added

- A built-in `chatgpt-connectors` skill guides agents using ChatGPT account connector tools: finding available connectors with Code Mode search, the `tools.chatgpt.<connector>.<operation>` paths, default permission asks, the Library prepare, upload, list, download and materialize operations, and how to respond to disabled connectors, profile changes, rejected requests and uncertain writes.
