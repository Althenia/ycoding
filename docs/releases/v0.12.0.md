# YCoding v0.12.0

## Added

- YCoding Interaction provides the native macOS helper and the matching Chrome extension for the `interaction` tool, the single built-in tool for browser and desktop interaction. The Browser and IsolatedBrowser HTTP and SDK contracts remain available.
- Queued messages appear in a compact tray directly above the composer on Web and Desktop. Collapsed, it shows the count and the first message; expanded, it lists every queued message in order with Remove and Steer now buttons. Only messages you wrote appear there.
- The HTTP API and the browser relay remove a queued input with `session.pending.remove` and promote it to a steer with `session.pending.steer`.
- Messages render Markdown, and fenced code blocks show as cards with a language label, a Wrap lines toggle, a Copy code button and syntax highlighting for Markdown, TypeScript, JavaScript, Rust, Python, JSON and Bash.
- User and assistant messages have a Copy message button that copies the exact message text.
- Sent messages show delivery state in place of the time: bouncing dots while sending, a check once sent and a green double check once YCoding has read it.
- Click a sent image thumbnail on Web or Desktop to open a full-size preview. Use Close, press Escape, or click the backdrop to dismiss it.
- Hard reviews show how long they have been waiting and flag stale requests. The TUI shows the review reason, Session ID and request ID.
- Retry shows the same pending hard review again without approving or running the action. Cancel closes the review without running the action.

## Changed

- To move to v0.12.0 from v0.11.12 or earlier, v0.12.1 through v0.12.3, or v0.12.4, use the current installer instead of the installed `ycoding update` command. The installer accepts the Interaction archive, verifies its signatures, and then retires the old helper during replacement. Load the bundled Chrome extension from the new installation.
- `ycoding update` without `--version` installs the latest release only when it is newer than the running version. When the running version is the same or newer, it says so and downloads nothing. `--version` still installs the named release, older or newer.
- Web and Desktop share one palette with clearer field and pane boundaries in light and dark themes, and a green interaction accent.
- The Web workspace shows a labeled activity bar for Projects, Sessions, Workspaces, Usage and Settings beside the Session list. A Hide session list button in the conversation header on Web and Desktop collapses the list to a full-width conversation and remembers the choice.
- While a Session runs, a thin trace follows the conversation header and branches when a child task starts. With reduced motion turned on, the trace shows as a static line.
- The composer keeps a fixed height while you type or paste, so the screen does not flicker or reflow, and it sits at the bottom of the window with no status strip below it.
- The model picker opens as a tall, scrollable list across providers.
- Prompts steered through Dots appear as right-aligned prompt bubbles with a ChatGPT badge and a Steer label beside it. Ordinary Dot messages do not show the Steer label.
- Desktop groups its Session list into Needs action, Running, Pinned and Recent, and its minimum window size is 1000×600.
- Desktop Settings, Projects, the Context tab and the Provider, MCP, Commands and Model dialogs fit the window without clipping or overlap. Escape closes a dialog and returns focus to the control that opened it.
- Web Settings groups Machine, Appearance, Notifications, Permissions and App into inset cards with aligned headings and controls. On phones, the full Keep machine awake guidance sits in a `Keep-awake safety details` disclosure while the battery and heat caution stays visible.
- Connect provider places each profile's type and connection status beside its name when space allows and wraps cleanly on smaller screens.
- Web New chat places the repository picker directly beside the composer, highlights it when a repository is required and keeps your draft while you choose. The phone landing composer has the same compact agent and model controls as chat.
- Project coordinators delegate all project work, including single-member work, through the appropriate supervisor or owner and never create, steer or manage member sessions directly.
- Agents treat cleanup as part of finishing a task. They remove its unused files and temporary output, and after confirming the merge they remove its worktree without `--force` and its branch with `git branch -d`, leaving active, shared or unmerged work in place.
- Built-in agents write direct, natural prose and avoid common AI writing habits.

## Fixed

- macOS installation verifies both the CLI executable and the Interaction helper against the YCoding signing certificate before replacing any files.
- Unanswered hard reviews expire after 24 hours by default without running the action. Set `guardrails.hard_review_expiry_minutes` to change the limit.
- Settled guardrail reviews clear from the waiting list, and the TUI refreshes pending reviews when it reconnects.
- Direct OpenAI Responses requests that continue a stored response no longer resend the system prompt, so input size stays flat and the prompt cache covers it across Steps.
- Pasted or attached screenshots show real thumbnails in the composer tray and in the sent message.
- Slash-command suggestions stay open after typing a namespace such as `/ui:`.
- Device-removal dialogs leave room between the warning and the actions, and the Back focus outline stays visible while scrolling phone Team and companion views.
