# YCoding v0.10.3

## Changed

- Answer a waiting subagent's full question from its parent Session's notice or the open Subagents list. Your literal answer is sent to the child question—not as a prompt or command—and resumes the child; your ordinary draft is kept and pending approvals still take precedence.
- Large Session skill, diagnostic, usage, and captured-change reads use bounded batches while preserving complete results and totals. This does not limit full model context or canonical transcript copy and export.
- Live Session updates are admitted only for the matching event type and Location, so unrelated project events do not accumulate in the Session listener.

## Fixed

- Captured shell output stays ordered and drains before command completion, even when output consumers fall behind.
