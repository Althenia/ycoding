# YCoding v0.11.7

## Added

- Desktop adds compact navigation drawers and responsive list/detail views for Workspaces, Sessions, Projects and Coordination, with explicit Back and Close actions and retained drafts and selection.

## Changed

- Desktop conversation content and the composer share a centered track. Tool and reasoning disclosures, provenance and long diff or output lines stay readable without widening the window; live composer actions keep stable, reachable positions.
- `/defer` toggles decision deferral for the Session family. Prompts, steers, commands, shell input and skill input keep it enabled until you explicitly turn it off.
- `/sleep` and `/wake` are removed. Use `/defer`, `/defer on` or `/defer off`.
- Deferred manual decisions wait in the review box while independent work continues. The family holds machine keep-awake, including after a backend restart. Upgrading preserves existing deferred state and review history.
- YOLO removes every blocker in its enabled category. Guardrails YOLO permits hard, catastrophic, destructive and custom-denied actions without review. Permissions YOLO permits denied and ceiling-limited requests; Project coordinators still delegate mutations to members.
- Answers YOLO handles option, multi-select, free-text, open and explicit-decision questions and Forms. A valid deterministic fallback keeps progression moving when the evaluator fails or refuses. Physical external authentication redirects remain external.
- YOLO takes precedence over Auto and Manual in managed-task inheritance. Enabling it settles existing waits and supersedes stale reviews without replaying actions.
- `/autonomous` and the TUI, Web and Desktop controls require explicit risk acceptance before enabling a new YOLO category. The warning makes full user responsibility clear; Cancel or Escape saves nothing.

## Fixed

- Remote connections wait until the local server is ready before loading Sessions. Stopping startup cancels pending connection work.
- A rejected single-use device refresh credential triggers one authentication attempt with the enrolled device key. Rejected or revoked device authentication still stops the connection.
- Desktop Session lists show confirmed root-family running and waiting status without listing helper or child Sessions as roots. Reported Master/member and direct-subagent relationships remain visible, and unavailable status stays unknown.
- Desktop worktree selection preserves repository context and unsent text when creation finishes after the selected repository changes. Unconfirmed creation remains reviewable without automatic retry.
