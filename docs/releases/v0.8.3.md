# YCoding v0.8.3

## Added

- The Usage screen reports Cursor plan quotas for a connected Cursor account: the Included, Auto, and API share of the current billing period, when that period resets, and the plan name beside the provider label. Shares Cursor does not report stay unreported instead of showing as zero.

## Fixed

- A connected Cursor account no longer lists no models. The provider reconciles its stored connection, so models appear even when the account was connected by another YCoding process or before the provider started listening for connection changes.
- A Cursor model sync that fails, for example when model discovery times out, keeps the models already published and is retried, instead of emptying the model list until the next connection change.
- A Session whose catalog read failed keeps the model and agent pickers usable: the failed read is retried on the next selection instead of being kept as the answer.

## Upgrade notes

- Run `ycoding update` on each machine. An account connected before this release lists its models within a minute of starting YCoding; reconnecting Cursor still applies them at once.
