# YCoding v0.11.3

## Changed

+ Web and Desktop share one refreshed workspace look, Direction A — Ledger.
+ The left rail is 256px wide. `[Y] YCoding` and a compact `New chat` button share the top row, followed by `Search sessions` and an `All · Waiting · Running · Idle` filter strip with counts. Sessions are flat single-line rows under a lowercase workspace heading, each with a leading status icon: a spinning arc for running, a hand and `Waiting` for waiting, an alert triangle for failed and a quiet dot for idle. The rows have no pin buttons and the rail has no machine footer.
+ The conversation header keeps the title, workspace and branch on one line, with compact icon actions at the end.
+ The open transcript shows assistant replies directly on the page. `Worked for … · N tools` and `N files changed +A −D` are flat inline rows that expand on demand. Your prompts sit in a right-aligned bubble with inline image thumbnails, file chips and a `Queued` receipt, and typing dots show while YCoding works.
+ The composer is one rounded card: the `Ask YCoding…` field on top, and attach, agent and model, effort, Autonomous and a round send button inside the same card. On phones the agent, model and status chips take their own line above the send controls.
+ The `Session companion` has text-only `Activity`, `Changes` and `Context` tabs. `Context` shows the `Active window` total on one line, a three-column breakdown and `Step & prompt cache diagnostics`, with links to `Open Usage · cumulative spend` and `Retained transcript messages`.
+ `Settings` is one open column: `Machine` with machine selection, rename and `Keep machine awake` first, then `Appearance`, `Notifications`, `Permissions` and `App`.
+ Web collapsible rows animate height and fade together when they expand or collapse; reduced motion removes the height motion and shortens the fade.
