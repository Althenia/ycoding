# YCoding v0.7.12

## Added

- See the files a Session changed in remote Conversation: an **Edited files** card after the latest reply lists each file with its added and removed lines, and expanding a file shows its latest change side by side on tablets and desktops or in one column on phones.
- Read captured file changes side by side in the TUI: an expanded file shows old lines on the left and new lines on the right when the transcript is at least 100 columns wide and `diffs.view` is `auto` or `split`; narrower terminals keep the single-column diff.
- Set a goal with `/goal <objective>`, change autonomy with `/yolo`, and load a slash skill with `/skill-name` from the remote composer, as in the TUI.

## Changed

- Let goal mode make open decisions on your behalf: the working agent and its automatic steers choose the safest reasonable option instead of asking you until the goal is satisfied. Reviews that require a human still come to you.
- Collapse the remote Sessions sidebar to a narrow strip that keeps its expand button in place; the sidebar button in the header is gone.
- Show the loaded Session count beside the workspace title on the Sessions page, above a full-width search field.
- Keep the installed remote app at a steady scale: pinch gestures and focusing a small text field no longer zoom the page. A browser tab still zooms.
- Give the Y in the YCoding app icon a small margin inside its tile.

## Fixed

- Stop sending `/goal`, `/yolo`, and slash-skill selections from the remote composer as ordinary messages. TUI-only actions such as `/cd` now say they are unavailable, and other text that starts with `/`, such as a file path, is still sent as a message.
- Open the Autonomy level and Goal panels next to their controls in the remote composer instead of far from them.
- Show the Goal control without empty space when no goal is active.
- Reject agent mentions from the remote workspace that the TUI would not offer, such as hidden or primary agents, instead of passing them to the Session.

## Upgrade notes

- Reload the remote workspace to load the updated browser client.
- Update YCoding on each machine, then open the TUI or run `ycoding service restart` so its background server runs the new version. Goal decisions, the TUI side-by-side diff, and the remote agent-mention check need the updated machine.
- An app installed from Chrome shows the new icon after Chrome refreshes it; reinstall the app from the browser to update the icon sooner.
