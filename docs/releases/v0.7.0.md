# YCoding v0.7.0

## Added

- Open recorded file patches from remote Activity without leaving the selected Session. Long diffs scroll within their row.

## Changed

- Use a responsive remote workspace for Sessions, conversation, Activity, approvals, and Settings across phone, tablet, and desktop layouts.
- Navigate refreshed landing, documentation, changelog, and offline pages in light and dark themes. The offline page offers a connection retry without queuing or sending work.

## Fixed

- Keep the selected machine and reconnect action when an account refresh reports it offline.
- Show a Session's project and directory only when the backend reports them, without inferring placement from its title.
