# YCoding v0.8.0

## Added

- **Multiplexed remote delivery.** One relay connection now carries three delivery classes: control frames first, then per-Session event batches and large reads interleaved so one Session's streaming or one long transcript read never blocks another. The browser can cancel a read it no longer needs and tells the backend when it is in the background so live output for the visible Session wins.
- **Windowed transcript and Session lists.** Long conversations and large Session lists mount only the rows near the reader. Paging older history keeps the visible row in place, following the streamed tail stays pinned, and keyboard focus stays on the focused row through scrolling.
- **`desktop.list` reports Space placement** for each window (`current_space`, `other_space`, `full_screen`, `unplaced`, `unknown`), and off-Space staging failures name the exact cause.

## Changed

- The web app is built on TanStack Router, Store, Query, Virtual, and Pacer. Routes keep the same URLs; connection-scoped reads (provider usage, keep-awake, workspace lists) refresh as Query resources that are discarded when the connection ends, and scroll, resize, and composer coalescing are paced rather than timer-driven.
- The reasoning effort control is a fluid pill slider: the fill follows the pointer live, snaps to the nearest offered effort on release, and shows effort-scaled sparkles; reduced motion removes the animation.
- The fast-model toggle shows a filled accent bolt when the paired fast model is active and a muted outline bolt when it is not.
- Manual **`/compact`** settles from the compaction job's durable completion or failure event, so a long compaction no longer raises a timeout warning while it is still running.
- A model without effort variants is reported without a variant. There is no `default` effort anywhere: Core, TUI, and web offer only the model's own variants, and an effort the model does not offer is rejected instead of being mapped.

## Fixed

- Switching to a model without effort variants no longer blocks the composer with a "saved effort is not offered" warning.
- On phones, the image lightbox is a fixed-height sheet: the caption and close controls stay at the top and the image fits within the sheet instead of extending past the viewport.
- A loaded tool image stays mounted when the first text of its assistant message arrives; the agent heading appearing no longer detaches and reloads the image.
- Computer-use desktop revisions ignore decorative Accessibility frame drift, so an unchanged window returns the same revision and a mutation issued a few seconds after its inspect is accepted.

## Upgrade notes

- **Breaking Change:** save unsent drafts and reload every open remote tab or installed web app after deployment. The relay protocol adds event-batch, cancel, and priority frames that the v0.7.18 client does not accept; a stale tab may reject frames and reconnect until reloaded. There is no old-client compatibility path.
- Run `ycoding update` on each machine, then reload the remote workspace or reopen the installed web app. Update the backend and browser client together for multiplexed delivery, background priority, and compaction settlement.
- Let running work finish before restarting the background server. `ycoding service restart` interrupts executing Sessions.
