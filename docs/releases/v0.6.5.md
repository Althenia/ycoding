# YCoding v0.6.5

## Changed

- Keep the selected credential profile visible beside the agent in the session header when a provider has multiple credentials.
- Rank mini prompt `@` agent and reference matches together while preserving backend file-search order.
- Distinguish rejected prompts and attachments from uncertain admission: corrected input after a definitive rejection gets a fresh prompt ID, while uncertain admission or wake retries reuse the exact ID and managed attachments.
- Move completed, cancelled, failed, and lost subagents into **Idle** in the team composer (**Subagents**, **Shell**, **Side chats**, **Idle**), with elapsed time frozen at completion and tasks ordered by lifecycle.
- Update built-in agent guidance for bounded repository searches and refine GSD's orchestration instructions.

## Fixed

- Drop a stored mini model variant when a resolved model offers no variants, while retaining it until the model catalog resolves.
