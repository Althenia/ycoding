# YCoding v0.13.1

## Changed

- Open `/remote` to work with enrolled Rust devices. `/remote/rust` redirects to the same workspace and preserves the rest of the path and its query. The hosted workspace now requires a Rust device.
- Built-in plugins run natively and can be selected with `plugins`. The Rust runtime supports configured native process extensions. To keep using JavaScript or TypeScript plugin files or npm plugin packages, stay on Bun 0.12.x.
- The manual macOS keep-awake setting stays on until you switch it off. YCoding releases its sleep holds when it stops and restores your manual choice at startup. Deferred Sessions restore their own holds separately.
- Set the starting model when calling `project` with `action: "create"`. The `model` object takes `providerID` and `id`, with optional `profile` and `variant`.

## Fixed

- Interrupting a Session waits for its current turn to settle before returning. Interrupting an idle Project Master saves the pause before replying, so after a restart the Project stays paused until resumed.
- The Web workspace reads and previews images in sent messages and waits for attachment uploads to finish before sending a prompt that references them.
- The Web workspace shows compaction progress only while compaction is running. The context indicator continues to show the last reported measurement until a newer measurement or a reset arrives.
- `execute` avoids building the full Project tool catalog up front. Tool discovery prepares the requested entries when you need them.
- OpenAI streams accept keepalive messages and retain transport error details when a connection fails. Chat Completions and Responses settle local tool calls only when the provider confirms that the turn can proceed.
