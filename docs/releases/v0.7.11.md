# YCoding v0.7.11

## Added

- See the selected Session's generation speed in the TUI sidebar: the latest tokens per second and a trend of recent Step requests. Speed appears only when the provider reports enough to measure it, and the sidebar hides it while the selected model differs from the one that produced it.
- See the selected Session's latest generation speed in the remote composer, with a compact recent trend where space allows.
- Track context-window use with a ring beside the model in the remote composer: hover over or focus it on desktop for the used and remaining share and token totals, or open the model row on a phone for a context bar.
- See compactions in a remote Conversation as dividers that show whether each is running, completed, cancelled, or superseded, with the Session's completed compaction count and saved tokens.
- Switch between a model and its fast counterpart with the lightning toggle in the remote composer's model control when the provider lists both; the reasoning level carries over when the counterpart offers it.

## Changed

- Keep the remote workspace mounted while you move between Sessions, Conversation, Office, Activity, Usage, and Settings: the previous view fades out instead of reloading, and each Session keeps its reading position.
- Leave the remote **New session** screen by choosing a Session, another page, or Back; it no longer has a close button, and the Session you choose opens with keyboard focus in its Conversation.
- Start remote Conversation history at the latest completed compaction, as the TUI does: only that compaction's card shows, and older history before it is no longer loaded.
- Animate pickers, sheets, dialogs, the phone Team sheet, the notification center, the Team confirmation, and the composer's Autonomy and Goal panels in and out. Closing returns focus to the control that opened them at once; reduced motion closes them without animation.
- Hide the Sessions sidebar next to a remote Conversation at tablet widths as well as on desktop; the browser remembers the choice.
- Give each effort level in the remote composer its own color, and show Goal as off after a goal finishes.
- Space the Running and recent page dots 24px apart.

## Fixed

- Show images attached to a remote prompt as thumbnails in Conversation instead of a tiny mark under the message, and show a prompt that has only attachments without an empty text bubble.
- Attach large images from an iPhone instead of failing with “Attachment data is not canonical base64.”, and show large images in Conversation instead of failing to load them.
- Keep the YCoding mark inside the installed web app icon and the iPhone Home Screen icon with the same margin as other app icons, instead of filling the icon edge to edge.
- Show Image unavailable with Retry when an image in Conversation has not loaded after two minutes, instead of loading indefinitely.
- Name the Session in each in-app notice and toast, including Sessions outside the loaded Sessions list; a notice never borrows the title of another Session. Desktop and push alerts keep their fixed wording.
- Keep subagents in Team and Office while their list refreshes, instead of briefly removing them when several updates arrive together.
- Keep the Sessions table, the Conversation sidebar, the Running and recent carousel, and the todo panel steady while they update: a changed search or filter keeps the current rows, marked busy, until the new list arrives.
- Stop the open notification center from flickering: routine updates no longer rebuild its rows or restart their animations.
- Wait 140 ms before showing remote loading placeholders when reduced motion is on too, so fast loads no longer flash a placeholder.
- Show a desktop alert even when the site's service worker is not yet registered or active, instead of dropping it.
- Load the Usage page after switching or reconnecting a machine instead of leaving it empty, and stop reporting the connection as open after Disconnect.
- Read an active local skill's supporting files through the `skill` tool instead of failing every time a model asks for one.
- Label a TUI tool call Cancelled only when it was cancelled; a failed skill call now shows as failed.
- Send TUI system notifications for a finished Session or a waiting question in terminals such as Ghostty before you first switch away from the TUI.
- Clear the TUI composer after a successful `/goal`, even when a permission prompt interrupts it, without a false “Failed to set goal” message.

## Upgrade notes

- Reload the remote workspace to load the updated browser client.
- Update YCoding on each machine, then open the TUI or run `ycoding service restart` so its background server runs the new version.
- Compaction dividers and generation speed in the remote workspace need the updated YCoding on the machine.
- An iPhone Home Screen icon keeps the image captured when it was added; remove it and add the remote workspace to the Home Screen again to get the new icon.
