# YCoding v0.13.0

## Changed

- The signed Rust CLI and Desktop downloads are for Apple Silicon. Rust uses its own `core.redb` store and does not import Bun Session history, Usage, or saved data.
- The default installer leaves an existing Bun installation or database alone. To stay on Bun, run `YCODING_VERSION=0.12.2 sh install.sh` using the downloaded installer. To replace the executable with Rust, let active Sessions finish and run `sh install.sh --replace-bun`. That command leaves your Bun database intact on disk.
- Promotion sets GitHub Latest to v0.13.0. Fresh shell installs select the highest stable Rust release still available. A bare `ycoding update` does not downgrade a newer installation; use `ycoding update --version 0.13.0` to select this version explicitly. Desktop rejects in-app downgrades; replace a newer Desktop bundle manually with the signed v0.13.0 bundle.
- Open `/remote` for Bun 0.12.x devices or `/remote/rust` for Rust devices. Both use the same Web sign-in, and existing Bun links still work.
- The Rust runtime uses the v5 WebSocket API for Session, Project, and configuration operations. Call a named operation with `ycoding api session.list`, or use a v5 client. The Bun REST routes for these operations are not available on Rust. Run `ycoding api --help` for operation syntax and `ycoding --help` for the Rust command list.

## Fixed

- Deferred Form answers use the original field names, including checkbox and number fields.
- A missing Project member directory no longer prevents startup. The Project keeps the member and its saved location.
- `ycoding service restart` waits for the old process to exit and release the store, even if its listener has already closed.
- A clean restart restores pending manual questions and Forms without reopening settled decisions.
- Dot and Remote clients reconnect after the server closes the socket with 1012 and opens a new epoch. Work tied to the old connection does not carry over to the new one.
- Remote connections refresh credentials and reconnect when relay credentials or delivery credit expire. Device revocation still stops reconnection.
- Cancelling or timing out a `glob` or `grep` call inside `execute` stops its Ripgrep process without blocking sibling tool calls.
- After an unexpected stop, startup marks incomplete tool-call arguments as unexecuted before closing the interrupted Step and does not replay unfinished calls.
