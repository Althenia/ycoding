# YCoding v0.5.0

## Added

- Responsive remote web workspace for viewing shared Sessions, sending prompts, following streamed output, answering requests, interrupting work, and controlling Session autonomy from a browser.
- Google sign-in, device enrollment, and explicit Session sharing through `ycoding remote`. Model, shell, tool, and filesystem execution remain on the enrolled machine.
- Public installation guides, documentation, and release history, with shared light and dark themes and reduced-motion support.

## Changed

- The terminal application and remote web client provide complementary views of the same local runtime. Remote commands are available in the standalone terminal executable as well as the full CLI.
- Remote conversations keep expanded output and draft text across streamed updates and reconnects. Additional terminal output can be loaded one page at a time without conflating paging with text expansion.

## Fixed

- Preserve Unicode characters across terminal-output page boundaries and avoid losing a trailing character when a running command settles during a read.
- Keep account loading distinct from signed-out state, and distinguish an explicitly unavailable local agent from a failed browser-to-relay connection.
- Prevent stale connection and Session reads from replacing the current selection, retain uncertain command outcomes without automatically replaying mutations, and update pending-request indicators after replies.
- Keep remote controls reachable at narrow widths and suppress control transitions when reduced motion is requested.
