# YCoding v0.10.6

## Added

- Muse (Meta) provider: connect a Meta Muse Code subscription through `/connect` → **Muse (Meta)** with a device-code login, or use a Meta Model API key or `META_API_KEY`. YCoding lists the models your account can use, with their context limits and effort levels, and runs them with tools and reasoning.
- Muse subscription quota appears in provider usage as live 5-hour window and weekly percentages with reset times, updated from each Muse response.
