# YCoding v0.13.3

## Fixed

- Rust sends Antigravity requests through the OAuth gateway and reports an incomplete response as a failure when the stream ends without a finish reason.
- The terminal composer uploads large clipboard images in chunks before sending the prompt, so the image does not have to fit in one message.
- Next-message suggestions in the terminal can include languages such as Thai that do not use spaces between words.
- After an unexpected stop, the server records the outcome of any tool still running as unknown. It does not retry the tool or resume the interrupted root Session.
- Project startup can pick up pending inputs that were admitted but never processed, without admitting them twice or replaying completed work. Paused Projects stay paused.
- Chrome enrollment requires a successful handshake with the signed macOS helper. Invalid profile labels are rejected before the consent prompt opens.
- The first Usage read can wait for accounting data to become ready rather than immediately reporting it unavailable.

## Changed

- A Dots thread response must contain either a decision or answers. Requests with both or neither are rejected.
