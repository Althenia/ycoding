# YCoding v0.2.0

## Added

- Session-owned terminal inspection with explicit control transfer, bounded output replay, and input disabled until reconnect synchronization completes.
- Explicit **Isolated browser** controls in the Session command palette, with temporary headless Chrome, semantic browser actions, permission checks, and Session guardrails. Initial support requires macOS arm64 and installed Google Chrome major 152. Browser state is discarded on stop; there is no personal-profile attachment, persistent login, or automatic restart.
- An optional unpacked Chrome extension for explicitly shared tabs, with installation-bound pairing, reconnect to the approved Session, and Forget pairing. Restart requires tabs to be shared again.
- macOS native computer operations for exact iTerm sessions and Finder paths, protected by Session ownership, revision checks, permissions, and guardrails. Existing macOS Automation authorization is required; YCoding does not prompt for or grant it.

## Changed

- **Breaking Change:** `ycoding run --auto` and boolean `--yolo` are removed. Use an explicit `--yolo 0`, `1`, `2`, or `3`. Omitting the option preserves an adopted Session's autonomy. Noninteractive runs fail on unresolved approvals rather than approving them locally.
- **Breaking Change:** PTY API operations now require Session identity and generation/control fences. API consumers must use the current generated client and obtain the appropriate inspect or control ticket before connecting; old unfenced requests are no longer supported.
- Hard guardrail reviews require a fresh human decision at every autonomy level, including YOLO 3.
- macOS release archives include the native computer helper alongside the terminal executable. Installer and self-update upgrades validate and preserve the previous pair, and attempt rollback if either replacement fails.

## Fixed

- Active provider event streams no longer end merely because an SSE retry directive is received.
- Terminal and composer recovery preserve explicit ownership and prevent stale or unsynchronized input.
- Isolated-browser startup/stop races, late results, cancellation, and browser loss settle without automatic mutation replay. Shutdown is bounded, and temporary owned resources are cleaned up.

## Limitations

- The selected-tab extension does not support navigate, click, or type: these operations fail closed because its debugger transport cannot enforce the required no-download boundary. Use separately started isolated mode for supported browser mutations; there is no automatic fallback.
- Native computer use is macOS-only and limited to the documented iTerm/Finder operations. Live application interaction and Automation authorization are environment-specific operator checks.
- Browser pause blocks new actions; it does not freeze website scripts. Stop is required to terminate the isolated browser.
- Published native archives use the Bun TUI runtime. Node SEA builds are not included in this release's distribution workflow.
