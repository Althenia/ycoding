# YCoding v0.6.3

## Added

+ Toggle Daybreak access per Session from the command palette or with the `/daybreak` slash command, optionally `blue`, `red`, or `off`. Without an argument it cycles off → blue → red → off, offering only the programs the active model actually advertises; the selection is stored durably per Session. Daybreak covers OpenAI's Trusted Access for Cyber program, Daybreak Blue and Daybreak Red.
+ While the Session selection is active with ChatGPT OAuth credentials on a model that advertises the program, requests to the Codex backend carry `access_programs.cyber` for reduced-refusal security work. API-key and custom-provider requests omit it, unadvertised models fail closed to standard safeguards, and provider authorization is still enforced.

## Changed

+ Daybreak availability is shown through the per-Session toggle instead of separate `· Daybreak Blue` and `· Daybreak Red` model-picker entries; the model list stays one entry per model.
+ Sessions that previously selected a removed `…-daybreak-*` model entry re-select the base model once.
