# YCoding v0.12.4

## Added

- YCoding Interaction provides the native macOS helper and the matching Chrome extension for the `interaction` tool. This is the single built-in tool for browser and desktop interaction. The Browser and IsolatedBrowser HTTP and SDK contracts remain available.

## Changed

- To upgrade from v0.12.3 or earlier, use the current installer instead of the installed `ycoding update` command. The installer accepts the Interaction archive and retires the old helper during replacement. Load the bundled Chrome extension from the new installation.

## Fixed

- macOS installation verifies both the CLI executable and the Interaction helper against the YCoding signing certificate before replacing any files.
