# YCoding v0.11.11

## Changed

+ A subagent that owns Project members notifies and wakes its parent when it reports new progress text or ends a turn with new final text, so its handback reaches the parent. Repeated text, empty final text and progress from subagents without owned members only update the stored task state.

## Fixed

+ Codex credits are shown as a credit count instead of dollars. Account-level credits are read whether or not the usage response nests its rate limit, and an account that reports no credits shows a zero balance instead of no credits window.
+ Gemini and Antigravity AI SDK streams that end with an in-stream provider error fail with that error's classification and message instead of "Provider ended the response without an answer and without a finish reason" or a completed partial answer. Overloaded and internal errors stay retryable; invalid-argument errors are not retried.
+ `ycoding decision watch` reports a timed-out Session as `unconfirmed` instead of `idle` when the work assessment could not be read before the deadline, and says that whether it is executing is unknown. `idle` requires a completed assessment.
+ Antigravity Gemini requests during text-only recovery and at the agent's step limit omit tool definitions and keep tool choice `none`, so recovery no longer offers tools the model may not call. A tool call emitted anyway is still rejected without execution, and recovery is still limited to one step. That single request misses the prompt cache, only after a silent step or at the step limit.
