# YCoding v0.7.4

## Fixed

- Pace remote requests within the relay's request limit so large Session inventories can load without a client-rate policy disconnect.
- Stop superseded Session list reads before fetching additional pages. Requests waiting to be sent are discarded when their connection closes, and mutations are never automatically replayed on reconnect.
- Wrap long machine names instead of truncating them. Desktop and phone picker options use compact text while preserving keyboard navigation, touch targets, and mobile selection confirmation.

## Remote workspace limitation

The workspace still loads the complete Session inventory and refreshes it after inventory notifications and reconnects. This release limits request rate; it does not replace full-inventory loading with on-demand pagination or eliminate its total traffic.

## Upgrade notes

- Reload the remote workspace to load the updated browser client.
- Existing device enrollments remain valid; these fixes require no re-enrollment or data migration.
