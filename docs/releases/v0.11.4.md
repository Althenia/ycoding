# YCoding v0.11.4

## Added

+ Provider usage can show best-effort USD balances for OpenAI API credits and managed Claude OAuth prepaid credits, separately from subscription quotas and recorded spend. Availability depends on the account; ordinary Anthropic API-key balances remain unavailable.
+ Normal Claude usage reads refresh missing or expired balance data. A failed refresh keeps observed subscription quota and shows a reporting warning instead of inventing a balance.

## Changed

+ Attach this computer to a Dot from the CLI, TUI or web connection dialog without disconnecting other computers. Choose the computer for the next turn in ChatGPT.
+ The `dots.attach` API accepts an explicit `replaceOthers` boolean: `replaceOthers: false` keeps other computers attached, while `replaceOthers: true` replaces the other attached desktops. Confirmation stays bound to the observed Dot, thread and computer. Failed or uncertain attachment is re-read, never automatically retried or switched to a replacing grant.
