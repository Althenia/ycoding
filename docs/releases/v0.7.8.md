# YCoding v0.7.8

## Added

- Turn remote access on and off from the TUI command palette with **Connect remote** and **Disconnect remote**. A status line at the bottom always shows whether remote is off, connecting, on, on in another process, or failed, and View status keeps the error message. The TUI remembers your choice and reconnects on launch. Only one connector runs per machine, so a `ycoding remote connect` already running in a terminal shows as on in another process.
- Open long remote conversations with the newest 100 messages and load older ones as you scroll up or choose Jump to top, without losing your place. A marker shows where the conversation begins.
- Show images in remote conversations: attached PNG, JPEG, GIF, and WebP images and images returned by tools appear as thumbnails that open in a full-size view. Other files show their name and size.
- List every running top-level Session from all workspaces at the top of the remote Sessions page.
- Show exact values when you hover over, focus, or tap a daily bar or provider segment in the remote Usage charts.

## Changed

- Place each Office character in the room for its current work: the Research lab while reading or searching, the QA lab while running tests, typechecks, or lint, the Meeting room while dispatching or steering subagents, and the Developer room otherwise. Idle characters relax in the Lounge. The CEO office is gone, and the office fills the canvas with no empty space around the map.
- Widen the remote transcript, place Jump to top and Jump to latest on its right edge, and narrow the prompt rail on wide screens.
- On phones, keep all five destinations in one row of icons in the bottom bar, open the Sessions menu as a sheet from the bottom, move the agent and model choices to their own row above the composer, and keep the workspace sheet's Confirm Selection button in view.
- Hide the remote todo panel once every task is completed, and hide Session-state and team-status notices in remote conversations, as the TUI does.
- Keep the previous rows in place while a remote Usage breakdown loads another page, group, or sort, instead of reloading the page.
- List YCoding local Today spend after all provider quotas in the TUI Usage view.

## Fixed

- Keep a Session usable when an attached file's stored copy is changed or removed. The model is told the file is unavailable, and the conversation continues instead of failing every prompt. Stored copies are now read-only, attaching the file again restores its stored copy, and resending an edited, reverted, or forked message with that file no longer fails.
- Keep requests working when a file in the conversation uses a format the selected provider cannot accept, or when a plugin's context hook fails; the model receives a notice instead.
- Carry the YOLO level and goal chosen on the TUI landing screen into the new Session before its first prompt runs. `/goal` on the landing screen also keeps the selected YOLO level.
- Load long remote conversations that previously failed to open, and keep loading the todo list, requests, file changes, and Office team when history cannot load. A very large live update no longer disconnects the remote workspace; its full content loads separately.
- Show one notification when a Session stops instead of duplicates, and notify about decisions that became pending and Sessions that stopped while the connection was down.
- Keep push alerts working: every push shows a notification, alerts continue after the machine reconnects, and Settings offers Re-enable when the device has lost its push subscription.
- Stop the status row that flashed above the remote composer while a prompt was sending.
- Align your pending prompts to the right on iPhone and iPad.
- Show the Office on phones, where it could render blank.

## Upgrade notes

- Reload the remote workspace to load the updated browser client.
- Update YCoding on each machine. The remote workspace reads conversation history in pages, so with an earlier version the conversation asks you to update the connected device.
- Restart YCoding to pick up the attachment and landing-screen fixes.
- If push alerts stopped, open Settings and choose Re-enable.
