# YCoding v0.12.2

## Changed

- Project supervisors resolve the folder or worktree for each new member. The Master enrolls the Session at that location, and the supervisor verifies the placement before sending the assignment.
- After delivery is verified, Project owners arrange archival for idle Sessions that are no longer needed. They leave active, waiting, or reusable Sessions open. Archiving keeps Session history.
- Built-in agents clean up only their own unused task files and clean, merged worktrees and branches. They keep shared files, tool caches, and the evidence needed to verify or roll back a release.
