# YCoding v0.7.7

## Added

- Attach files to remote prompts and commands by pasting from the clipboard, choosing them with the attach button, or dropping them on the composer. Each file can be up to 20 MiB and shows its name, size, and an image preview, then upload progress with a cancel control. A failed or cancelled upload keeps the draft and its attachments. Uploads pass through the relay, so a 1 MB file takes about 20 seconds.
- Show the selected Session's todo list directly above the remote composer. The collapsed summary shows completed and total tasks and the task in progress; expanding it lists every task without covering the transcript, and the browser remembers whether it was open.
- Follow new output in a remote conversation while you are at the bottom, stop following when you scroll up to read, and return with Jump to latest. Screens at least 1024 px wide also show a prompt rail that previews each of your prompts and scrolls to it.
- Show new in-app notices as up to three toasts for about six seconds. Hovering over or focusing a toast pauses it, and Open goes to its Session.

## Changed

- Redesign the remote composer as a floating rounded card that holds the agent picker, a model and effort control, the Session status, and a Steer or Queue toggle. The rest of the remote workspace uses rounded controls and cards to match.
- Group the notification center by day, mark notices read when you open it, and add Mark all read, Clear all, and per-notice dismissal.
- Show subagent notices in remote conversations as compact status rows with an expandable excerpt.
- Redesign the remote Usage page with provider quota cards, spend tiles with a 30-day trend, a daily chart next to this month's spend by provider, and a sortable breakdown table that becomes a list on phones.
- Make motion on the public site, documentation, and changelog more noticeable: content fades and rises into place, sections appear as they scroll into view, and the documentation contents marker slides to the current section. Reduced-motion readers and pages without JavaScript see the final state.

## Fixed

- Show running Sessions as running in the remote workspace and the Office when the machine keeps Sessions whose folders were deleted.
- Name a workspace opened through a path containing `..` by its folder instead of `..`.
- Keep the Office Agents list from flickering, keep subagents visible across refreshes, and seat a running main Session at its desk instead of the lounge.
- List every matching skill, command, agent, reference, and file in remote composer autocomplete instead of only the first eight, with aligned descriptions.
- Keep the remote composer the same height when you hover over or focus its text field.
- Keep TUI autocomplete scrolling in place under the mouse wheel, and make every suggestion reachable instead of cutting lists to a fixed length.

## Upgrade notes

- Reload the remote workspace to load the updated browser client.
- Update YCoding on each machine to attach files, see todo lists, and get the running-status and workspace-name fixes. With an earlier version, the todo list stays hidden, and an upload stops after about 10 seconds with a message to update YCoding on that machine.
