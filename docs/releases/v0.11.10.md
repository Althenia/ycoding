# YCoding v0.11.10

## Added

- Attach an existing root Session to a Project from the TUI, Desktop, or Web without moving or restarting it. Detaching a settled member preserves its Session and history.

## Fixed

- Project folder pickers accept Windows drive and network-share paths for Windows backends. Home-relative paths resolve on the selected backend rather than on the client.
- Browser controls find options in open dropdowns and confirm the selected value before reporting success. Enter and Space activate focused controls, and fields labeled Account Code are not mistaken for one-time-code fields.
