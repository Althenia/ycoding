# YCoding v0.7.9

## Added

- Manage every directory YCoding knows with **Manage workspaces** (`/workspaces`) in the TUI command palette. It lists recorded project directories and every directory that holds a Session, grouped by project, 50 at a time, and searches by directory path or project name. Press `enter` to open a directory so your next new Session starts there, `ctrl+d` twice to delete a project copy, `ctrl+x` to forget a directory after confirming, or `ctrl+r` to reload. Forgetting a directory permanently deletes that project's Sessions in it, including their child Sessions; files on disk are not touched.
- Reload configuration and provider models without restarting through **Refresh models and providers** in the TUI command palette. It picks up a project `ycoding.json`, `ycoding.jsonc`, or `.ycoding` created after YCoding started and reruns provider model discovery. Environment variables do not change through a refresh.
- Manage a Session's team from the new **Team** panel in the remote Conversation, on desktop, tablet, and phone. Open a subagent, answer its question in place, or cancel it after confirming, and see its status, agent, model, elapsed time, and reported usage. Read a shell's output in pages or kill it after confirming. Browse side chats or start one with the parent's recent history. An action whose outcome is uncertain is never resent automatically.

## Changed

- Replace the TUI's **Connect remote** and **Disconnect remote** commands and the bottom status line with one **Remote connection** toggle in the command palette. Its indicator is green when remote is on in this TUI or in another process, and grey when it is off, connecting, or failed. View status still shows the error or the other process's PID.
- Open subagents read-only in the remote Conversation: a context bar with Main, Previous, and Next navigation, in-place answers, and reported usage replaces the composer. Updated machines reject prompts, commands, skills, attachments, and model, agent, autonomy, or goal changes sent to a subagent. Side chats still accept prompts.
- Show what each Office character is actually doing, such as “Reading store.ts” or “Running bun test”, in its speech bubble and the Agents list. Each character follows its own Session, so the main agent relaxes in the Lounge while only its subagents work, and idle or finished characters show no status bubble.
- Show Office only on tablets and desktops: viewports narrower than 768px, and touch screens shorter than 600px, stay on Conversation and hide the Office switch and Office settings.
- Show running Sessions from every workspace as a swipeable carousel at the top of the remote Sessions page, with pagination dots when the cards overflow.
- Keep the remote Conversation sidebar on the open Session's workspace: it shows the workspace as a heading instead of a picker, lists running Sessions first, and highlights the main Session while one of its subagents is open. Choose another workspace from the Sessions page.
- Stack Usage spend tiles in one column on phones and tablets so long values stay intact.
- Return a local skill's supporting files as absolute paths that the agent reads directly with the `read` tool. The skill tool's `resource` input now reads only from MCP-served skills.

## Fixed

- Stop images in remote conversations from flickering and reloading while the conversation updates.
- Stop remote Usage cards from flickering and replaying their entrance animation on reconnects and refreshes. Previous values stay visible until new ones arrive, and switching machines, disconnecting, or signing out clears them.
- Keep the Office scene in place when you select another member of the same team, instead of resetting every character.
- Show only matching Sessions while a remote search or status filter is active. Opening a Session clears both filters.

## Upgrade notes

- Reload the remote workspace to load the updated browser client.
- Update YCoding on each machine. The Team panel and Office activity need the updated version, and a machine running an earlier version shows an update note instead. Only updated machines reject input sent to subagents.
- Restart YCoding to use Manage workspaces, Refresh models and providers, and the Remote connection toggle.
