# YCoding v0.4.2

## Changed

- YCoding is terminal-only. The terminal application is the primary and only product and release surface; there is no desktop client.
- The per-version release notes at `docs/releases/v<version>.md` remain the GitHub release notes.

## Fixed

- Removed stale desktop-client references from the product guides, contributor guides, packaging contract, and built-in skill guide so agent prompts no longer carry a second presentation surface.
