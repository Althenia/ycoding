# YCoding v0.11.12

## Changed

- Collapse the Project header details or hide the context sidebar to make more room for the conversation. Project navigation and conversation controls stay available.
- Search for a model in a picker that fits the available screen space. Closing the picker returns focus to the model control.
- Project start and progress updates appear as plain notices in the Web transcript, as in the terminal. They do not create member cards, Open buttons, or prompt ticks.
