# YCoding v0.11.2

## Added

+ The desktop app updates itself. `Check for updates` and `Update & Relaunch` are in `Settings` → `Updates`, in the command palette, and under `YCoding Desktop` → `Check for Updates…` in the macOS menu bar. Before it replaces the `.app` bundle, the app verifies the HTTPS GitHub release metadata, the SHA-256 checksum against `ycoding-<version>-checksums.txt`, the bundle identifier `app.ycoding.desktop`, and the pinned YCoding Code Signing certificate. If the swap fails, the previous bundle is restored.
+ The desktop app has a macOS application menu with `YCoding Desktop`, `File`, `Edit`, `View` and `Window` menus. `Edit` uses the native responder roles `Undo`, `Redo`, `Cut`, `Copy`, `Paste`, `Paste and Match Style`, `Delete` and `Select All`.
+ The desktop composer falls back to a native clipboard call for pasted text and files. `/copy` and `/export` write to the clipboard through the same call.

## Changed

+ The desktop app opens the workspace right away. The `Connecting to your workspace` screen is gone: the workspace shows loading skeletons while it connects, and only a failed connection shows an inline alert with `Retry` and `Open Settings`.
+ `Selected machine` and `Switch backend` moved out of the left session rail into `Settings` → `Machine & Backend`, which shows `This Mac`, the connection state, ownership, the backend version, the backend mode, the shared endpoint and `Apply & Reconnect`. The rail now ends with the `Projects`, `Sessions`, `Workspaces`, `Usage` and `Settings` destinations.
+ The desktop rail, conversation header, stream, composer capsule, companion pane and two-column `Settings` grid use a flat ledger workspace layout: one `--yc-surface` rail and companion on either side of the `--yc-bg` conversation, divided by 1px hairlines, with underline companion tabs and tabular token figures in the `Context` tab.

## Fixed

+ Copy, paste, cut, select all, undo and redo work in the desktop composer under macOS `WKWebView`. `Enter` sends and `Shift+Enter` inserts a newline.
+ The desktop app attaches to the local `ycoding` background service, or starts it with `serve --service` when it is not running, and ignores a version mismatch in shared mode.
+ When a saved loopback `sharedEndpoint` (`127.0.0.1` or `localhost`) is unreachable or answers `401 Unauthorized`, the desktop app falls back to the local managed service. Startup and reconnect retries back off within a bounded delay.

## Limits

+ The desktop app targets Apple silicon macOS (`darwin-arm64`) only. It is signed with the self-signed YCoding Code Signing certificate and not notarized, so Gatekeeper still blocks the first open until you allow it.
+ In-place updates need a `.app` bundle in a location the current user can write to. Otherwise `Updates` reports that the update cannot be installed and states why.
