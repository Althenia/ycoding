# YCoding v0.11.2

## Added

+ Fill or clear ordinary form inputs, select options, set checkbox or radio state and hover over elements. Observations include bounded control values and checked, selected, expanded and pressed state while withholding sensitive values.
+ Wait explicitly for element attachment or visibility, a URL, page load or matching text. Network-idle waits require a continuous 500 ms interval with no tracked requests in flight.
+ Fill date, time, datetime-local, month, week, color and range controls, including controls in approved same-origin frames.

## Changed

+ Browser errors distinguish a tab in another mode, a departed tab and an unknown tab. When a departed tab has a successor tab, inspect that successor before continuing.
+ Browser-routing guidance allows another explicitly authorized browser route under the same permission, guardrail, credential and confirmation rules.
+ Computer-control guidance describes target-process activation and key-window records for background input, and warns that concurrent typing may reach the controlled application.
+ Isolated browser results include bounded control state and matched-frame information, suppress sensitive values and messages, and discard unsafe frame URLs.
+ Editing keys require verified, attached, non-sensitive focus on both browser execution paths. Only plain Tab, Escape, arrows, Home, End, PageUp, PageDown and Shift+Tab bypass inspection; uninspectable or sensitive editing targets refuse before dispatch.
+ After upgrading the CLI, update or reload the bundled Chrome extension before pairing or continuing browser control. Bridge version 6 rejects version 5 peers. Matching packaged versions do not prove an installed extension has reloaded.
+ Supporting files for an active skill stay with the exact SKILL.md source loaded for that activation, even if its catalog entry changes or disappears. Only the requested resource is read; no whole bundle is injected and no other same-named source is searched.
+ Missing skill source provenance refuses supporting-file reads instead of guessing another bundle; complete compaction or switch agents before loading the skill again. Successful reads return current file content and retain containment, read permissions and capability checks.
+ Built-in primary (`GSD`, `architech`, `god`, `yangi`) and task-subagent (`occam`, `omoikane`, `wittgenstein`, `zeus`) prompts sharpen each specialist's posture: relentless output-driven completion (`GSD`, `zeus`), big-picture system direction and add/remove gap analysis (`architech`, `omoikane`), intuitive context inference from live evidence without unnecessary questions (`god`, `zeus`), and immediate no-questions execution along the minimal proven path (`yangi`, `occam`, `wittgenstein`).
