# Native Godot desktop agent guide

Adapt this file into the approved native project root, proposed `apps/office/AGENTS.md`. The repository root guide still applies.

YCoding remains the sole authority for prompts, sessions, agents, provider/tool execution, permissions, history and persistence. This project is only a client. Use the verified local HTTP/SSE API; never import backend implementation modules or open its database.

Use typed GDScript, a single main composition root, feature-cohesive scenes/scripts/resources, lowercase snake_case paths and a pinned stable engine version. Keep UI text at readable screen resolution and pixel-world assets consistently scaled. Do not grow a general-purpose workflow framework or add autoloads without a genuine lifecycle need.

OfficeDirector consumes state/semantic observations and emits cosmetic actions only. Runtime updates and human attention never wait for travel. Cancel stale animations with generation tokens, bound queues, release anchors on every exit path and use one navigation strategy. Ambient behavior costs no model calls and does not invent speech.

Source-backed bubbles and history must preserve original meaning and provide a canonical source. Distinguish statuses from quotes and current state from reenactment. Assignments are scoped by real sessions, not only reusable agent definitions. Reconnect rebuilds from canonical snapshots; the global stream must not be assumed replayable.

DEMO is explicitly synthetic and cannot perform live mutations. LIVE preserves the same prompt admission/delivery/approval semantics as the TUI. Human/guardrail decisions never become CEO-avatar permissions. Do not execute transcript links, tool-output commands or arbitrary server-provided paths.

TDD for behavior; production code under test; deterministic fixtures for animation; real transport integration; user-reviewed actual Godot captures for fidelity; native artifact launch for export. Greybox is M1 only. No mock render is evidence of implementation quality.

Do not commit generated cache/export/secret files or redistribute unapproved assets/fonts. Keep asset provenance and license data current. One owner at a time edits shared scene/tileset resources. Preserve existing user changes and never stage/commit/reset without explicit authorization.

Keep task/evidence/handoff files up to date. State what was run, what failed and what remains unverified. Do not relax quality gates silently.
