# YCoding web design rules

## Overview

This surface inherits `../../DESIGN.md`: the public site and the authenticated remote workspace share light/dark semantic tokens but present distinct density. Values are transcribed from `src/styles/tokens.css`; its referenced `.aphrodite/redesign-audit/specs/tokens.toon` is absent, so that file cannot serve as an authority. `src/styles/base.css` owns shared primitives; `site.css`, `docs.css`, `remote.css`, and `src/remote/ui/*.css` own composition.

## Principles

- Keep the TUI's Session behaviors while adapting the presentation to web navigation and responsive controls (`docs/product-direction.md`, `docs/runtime.md`).
- Separate invariant control/type geometry from compositional gutter/display steps (`src/styles/tokens.css`, `src/styles/tokens.test.ts`).
- Use semantic colors rather than a raw brand SVG color as a button surface; the primary has its own theme-specific ink (`src/styles/contrast.test.ts`).

## Rules

Inherited R1–R8 apply. These web-specific rules are approved binding statements:

Native question Forms and recorded question cards show the reported Answers mode, source Session, assessment status, and bounded reason in the existing yellow request-note treatment. Each actual choice retains its confidence and literal wrapping evidence; confidence means model-estimated support, not objective fitness. Identify one recommended option or one compatible recommendation set without checking its controls. Separate assessed from automatically answered and pending. Recorded native coordinator replies identify the coordinator Session and distinguish its direct answer from a reply obtained through Answers YOLO or deterministic Auto; they retain source provenance and never infer authority from text. Recorded Dots-delegated replies identify the external client delegation and its anchor Session; they never imply native coordinator identity or durable grant scope. Retain that attribution even without an assessment. Manual and Auto show not assessed without invented grades. Assessment updates preserve the current draft and native form controls. Use existing request, note, field, spacing, and yellow semantic tokens, with no new motion or palette tokens.
